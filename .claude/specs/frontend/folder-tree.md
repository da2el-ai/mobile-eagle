# フォルダツリーダイアログ 仕様書

## 1. 概要

ヘッダーのハンバーガーボタンから呼び出す、画面左端のモーダル。
Windows のエクスプローラーのような折りたたみツリーでフォルダを選び、グリッドビューのフォルダを切り替える。

## 2. 関連ドキュメント

- 共通基盤: [base.md](base.md)
- モックアップ: `.claude/design/Mobile Eagle.dc.html`（Folder tree dialog セクション）

## 3. レイアウト

- 背景スクリム `--scrim`（クリックで閉じる）
- 本体: 画面左端に `width: 320px; max-width: 85vw; height: 100vh`、背景 `--panel`、
  左からのスライドイン（`translateX(-100%) → 0`、0.22s）
- ヘッダー行（sticky）: タイトル「フォルダ」+ 閉じるボタン
- 本文: フォルダ行の縦リスト（内部スクロール）
- **設定ボタンは置かない**（ヘッダービューへ移動済み。grid.md 3.1）

## 4. ツリーの内容

先頭に仮想フォルダ 2 行、続いてライブラリのフォルダツリーを表示する。

| 行 | folderId | 件数表示 |
| --- | --- | --- |
| すべて | `all` | 全アイテム数（`folders` store の `totalCount`。バックエンド拡張。base.md 10 章。フォルダ件数の合算では複数フォルダ所属分が二重計上されるため使わない） |
| 未分類 | `uncategorized` | `folders` store の `uncategorizedCount`（バックエンド拡張。base.md 10 章） |
| （以下、実フォルダの再帰ツリー） | 実 ID | 合算件数（下記） |

- **「すべて」「未分類」は子を持たない並列の行**として置く（両行にキャレットは付かない）。
  モックアップは「すべて」をツリーのルートにして実フォルダをその子として描いているが、
  未分類の行が無い構造のため踏襲しない
- 実フォルダの件数は「直下の `imageCount` + 全子孫の合算」。合算は **getter（computed）で算出**し、
  元データを破壊的に書き換えない（旧 `calculateTotalImageCount()` は `imageCount` を直接加算しており、
  再取得時に二重加算するバグの温床だった）
- 親子の両方に属するアイテムが二重計上される既知の不正確さは当面許容する（base.md 15 章）

## 5. フォルダ行の挙動

`▶ {フォルダ名}（{件数}）` を 1 行 36px で表示する。

- **▶（キャレット）**: 子フォルダを持つ行のみ表示。タップで展開/折りたたみをトグルし、
  展開中は `▽`（下向き）になる。タップ領域は 26×34px 以上
- 子フォルダはインデント（1 階層 16px）して表示する
- **行本体のタップ**: そのフォルダへ移動（`router.push('/folder/{id}')`）し、ダイアログを閉じる。
  クリック領域はテキストだけでなく**行の横幅いっぱい**
- 現在表示中のフォルダの行は強調する（背景 `--hover` + bold）
- フォルダ名は ellipsis で省略。件数は行の右端に `--muted` で表示
- 展開状態はメモリ上（`ui` store もしくはコンポーネントローカル）で保持する。
  永続化はしない（セッション内で維持されれば十分）

## 6. 閉じる操作

1. 背景スクリムのタップ
2. ヘッダーの × ボタン
3. フォルダ行のタップ（移動と同時に閉じる）

## 7. エッジケース

| ケース | 挙動 |
| --- | --- |
| フォルダが 1 つも無いライブラリ | 「すべて」「未分類」のみ表示 |
| 未分類が 0 件 | 行は表示する（件数 0）。タップ可 |
| 深い階層（5 階層超） | インデントで幅が窮屈になるが折りたたみで運用可。特別対応しない |
| フォルダ移動後の再オープン | 展開状態は前回のまま。現在フォルダの強調が更新されている |
| ツリー表示中に自動リロード | 自動リロードではフォルダ一覧を再取得しない（オープン課題参照。**フォルダ移動の成功時のみ** grid.md 5.5 が `folders.load()` を再実行する） |
