# 設定ダイアログ・設定の永続化 仕様書

## 1. 概要

ヘッダーの設定ボタンから開く設定ダイアログと、フロントエンド設定の永続化
（`use-settings.ts`）の仕様。テーマ・自動更新・画質・グリッド表示状態を扱う。

## 3. 設定ダイアログ

ヘッダーの設定ボタンから開くモーダル（上寄せ・max-width 480px・max-height 88vh。
フィルタダイアログと同じ枠コンポーネントを使う）。項目は「見出し / 内容」の縦並び。

| 項目 | UI | 値 | 既定 |
| --- | --- | --- | --- |
| テーマ | チップ 3 択 | ライト / ダーク / 自動（OS 依存） | **ライト** |
| 自動更新 | チップ 2 択 | 有効 / 無効 | 有効 |
| 自動更新間隔（秒） | 数値入力 | 2〜120 | 10 |
| ファイルサイズ上限（KB） | 数値入力 | 0 = 圧縮しない / 空欄 = 768 | 空欄（=768） |
| JPEG 圧縮率 | 数値入力 | 1〜100 / 空欄 = 85 | 空欄（=85） |
| ライブラリ | ボタン「ライブラリを再読み込み」 | —（設定値ではなく操作） | — |

- 説明文（`--muted` 12px）:
  - 自動更新間隔:「2〜120秒（規定 10 秒）」
  - ファイルサイズ上限:「この値より大きい画像は圧縮して表示します。0 = 圧縮しない / 空欄 = 768」
  - JPEG 圧縮率:「空欄 = 85」
- **保存ボタンは置かない。変更は即時反映・即時保存**する（モックアップの構成に従う。
  旧実装の「項目によって保存タイミングが違う」非対称を解消）
  - チップ: タップで即反映・即保存
  - 数値入力: 入力のたびに反映するが、**blur（またはダイアログを閉じる）時に範囲外を clamp**
    して確定・保存する
- テーマの変更は `use-theme.ts`（base.md 5.1）を通じて即座に画面へ反映される
- 自動更新の ON/OFF・間隔の変更は自動リロードのタイマーへ即座に反映される（grid.md 6.2）
- 数値入力は `font-size: 16px` 以上（iPhone ズーム対策。base.md 5.2）
- 「ライブラリを再読み込み」はバージョン表記の上に置く。仕様は [library-reload.md](library-reload.md)
- **ダイアログ最下部に `v{version}` を表示する**（`--muted` 12px・中央寄せ）。
  値は `GET /api/version`（backend/base.md 6 章）から取得し、`use-version.ts` が
  モジュールスコープに保持する。**アプリ起動時に一度だけ取得**し、ダイアログを開くたびの通信はしない。
  取得できなかった場合は表示しない（補助情報のため画面は壊さない）

## 4. 設定の永続化（`use-settings.ts`）

- **シングルトン**の composable とする（旧実装で「呼ぶたびに別インスタンスが生成され
  状態が共有されない」不具合が実際に起きた。モジュールスコープに単一の state を置く）
- 保存先: `localStorage`。**単一キー `mobile-eagle-viewer-settings`** に JSON で保存
  （項目追加に強くするため。プラグイン側の `mobile-eagle-settings` とは実行環境が別
  ＝ブラウザの localStorage であり、衝突しない）
- 読み込み: 初回アクセス時に一度だけ。壊れた JSON・未知の値は既定値へフォールバック
- 保存: 変更のたびに全体を書き戻す

### スキーマ

```json
{
  "theme": "light",            // 'light' | 'dark' | 'auto'
  "autoReload": true,          // 自動更新
  "autoReloadInterval": 10,    // 秒。2〜120 に clamp
  "maxFileSize": null,         // KB。null = 既定(768) / 0 = 圧縮しない
  "quality": null,             // 1〜100。null = 既定(85)
  "gridCols": 4,               // グリッド列数（グリッドコントローラーが変更）
  "objectFit": "cover"         // 'cover' | 'contain'（同上）
}
```

- `gridCols` / `objectFit` は設定ダイアログには**表示しない**（グリッドコントローラーから
  変更する。grid.md 3.5）。保存の仕組みだけ共有する
- `maxFileSize` / `quality` は `get_image` の query に使う。**null（空欄）のときも
  表示既定の値（768 / 85）を明示的に送る**。バックエンドの既定値（`max_file_size` = 1480）に
  依存すると「空欄 = 768」の表示と実挙動がずれるため、query は常に両方付ける

## 5. エッジケース

| ケース | 挙動 |
| --- | --- |
| localStorage が使えない（プライベートモード等） | メモリ上の既定値で動作。保存はサイレントに失敗（トーストは出さない） |
| 数値に範囲外・非数値を入力 | blur 時に clamp / 直前の有効値へ戻す |
| 自動更新間隔を変更 | タイマー再起動。ポーリング中のリクエストは結果を捨てる |
| テーマ「自動」で OS テーマが変わる | matchMedia の change で即追従（base.md 5.1） |
| 別タブでの設定変更 | 追従しない（`storage` イベントは監視しない。個人用ツールのため許容） |
