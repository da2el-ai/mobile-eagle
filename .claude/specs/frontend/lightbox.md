# Lightbox・メタデータビュー 仕様書

## 1. 概要

サムネイルのタップで開く全画面モーダル。画像の拡大表示・前後移動・メタデータ表示・
レーティング変更・削除を行う。

開閉は **route query `image={itemId}`** で制御する（base.md 7 章。ブラウザバックで閉じられ、
フィルタ文脈を失わない）。

## 2. 関連ドキュメント

- 共通基盤: [base.md](base.md)
- モックアップ: `.claude/design/Mobile Eagle.dc.html`（Lightbox セクション）

## 3. レイアウト・表示要素

- 全画面（z-index 80）。**背景は `#232729` / opacity 1**（テーマによらず固定。半透明にしない）
- 縦のレイアウトは `display: grid; grid-template-rows: 1fr 88px`:
  上段が画像エリア、**下段（88px）がサムネイルリストビュー（5 章）**。
  画像エリアはリストビューの高さ分小さくなる
- **画像**: 画像エリア内に `max-width/max-height: 100%; object-fit: contain`（縦横中央）。
  `src` は `/api/eagle/get_image?id=&max_file_size=&quality=`（設定値を付与。settings.md）
- **閉じるボタン**: 右上固定（42px 円形、黒半透明地）
- **前後移動ボタン**: 画面の左右両端に `width: min(200px, 20vw); height: calc(100vh - 88px)` の
  透明ボタン（リストビューには被せない）。押下中は `background: #ffffff42` で押下範囲を
  可視化する。**インラインで `background` を直書きしない**（詳細度でクラス指定が負ける —
  モックアップ制作時に実際に踏んだ罠）
  - **押下状態は CSS の `:active` ではなく pointer イベントで自前に持つ。**
    `:active` は iOS Safari では発火せず、PC だけ白くなってスマホで無反応になる
    （実機で確認）。`pointerdown` / `pointerup` / `pointercancel` / `pointerleave` で
    状態を更新し、`bg-transparent` と押下色を**排他のクラス**として当てる
    （両方同時に付けると、どちらが勝つかは生成 CSS の順序次第で不安定）
  - 前後移動でボタン自体が消えると `pointerup` を受け取れないため、
    表示画像が変わったら押下状態をリセットする
- グリッドコントローラーは Lightbox 表示中は**非表示**にする（grid.md 3.5 と統一）。
  ヘッダーは背面に隠れる（操作不可）

## 4. 操作

| 操作 | 動作 |
| --- | --- |
| 画像タップ | メタデータビューの表示 / 非表示をトグル |
| 左右端ボタン | 前後のアイテムへ移動（**メタデータビュー表示中でも動く**） |
| 閉じるボタン / ブラウザバック | Lightbox を閉じる（query から `image` を除去） |

- 前後移動の対象は**現在の一覧（フォルダ + フィルタ + 表示順）のロード済みアイテム**。
  先頭 / 末尾では該当方向へ移動しない
- 前後移動は `router.replace` で query を書き換える（履歴を積まない。バック 1 回で
  グリッドへ戻れるようにする）
- 開くときは `router.push`（グリッドへ戻るための履歴を 1 つだけ積む）
- 末尾付近まで移動したら次ページの先読み（`loadNextPage()`）を発火してよい
- **スワイプによる前後移動・独自のピンチズームは実装しない**（ユーザー決定 2026-07-18。
  ズームはブラウザ標準のピンチで実現できており、スワイプを実装するとピンチとの判別が
  難しく誤動作の原因になるため。前後移動は左右端ボタンとサムネイルリストビューで行う）

## 5. サムネイルリストビュー

画像エリアの下（下段 88px）に、一覧のサムネイルを横に並べて表示する（iOS 写真アプリ風）。
Lightbox 表示中は常時表示する。

**レイアウト**:

- 高さ 88px（サムネイル 64px + 上下パディング 12px）。背景 `rgba(0,0,0,.5)` + blur
- サムネイルは **64×64px の正方形**・`object-fit: cover`（トリミング）・角丸 6px・間隔 6px
- 左右パディングは `calc(50% - 32px)`（先頭・末尾のサムネイルも画面中央に来られるようにする）
- **現在の画像が中央**に来るようスクロールする（開いた直後は即座に、前後移動・タップでの
  切り替え時はスムーズスクロール）
- 現在の画像は枠線（白 2px）つき・opacity 1。**それ以外は opacity 0.6**
- サムネイルは `loading="lazy"`（一覧の全ロード済みアイテム分を並べるため）

**操作**:

- **タップ**: その画像に Lightbox を切り替える（`router.replace` で `image=` を更新し、
  中央へスクロール）
- **ドラッグでスクロール**: Pointer Events で実装。**移動距離 4px 以上でドラッグと判定**し、
  それ未満はタップ（クリック）として扱う。ドラッグ後のクリックイベントは抑止する
  （capture フェーズで suppress）。`touch-action: pan-x`・`setPointerCapture` を使い、
  画像の `draggable` は無効化する
- リストの**末尾**付近までスクロール・移動したら `loadNextPage()` の先読みを発火してよい
- **先頭方向の先読みは不要**（一覧は常にページ 0 から連続で保持されるため（base.md 8 章）、
  Lightbox をリスト途中の画像から開いても、それより先頭側は定義上すべてロード済み。
  未ロード領域が生じるのは末尾方向だけ）

## 6. メタデータビュー

画像タップでオーバーレイ表示する下部シート（旧実装の「画像の下に常設」から変更）。

- `position: fixed; left: 0; bottom: 88px; width: 100vw; max-height: 50vh; overflow-y: auto`
  （**サムネイルリストビューの上に重なる位置**。`bottom` はリストビューの高さ分）
  - **`max-height` は 50vh**。モックアップの `calc(88vh - 88px)` では、メモやタグが多い
    アイテムでシートが画面をほぼ覆い尽くし、背後の画像が見えなくなる（実機で確認）
- 背景 `rgba(0,0,0,.82)`。文字は白（テーマによらず固定）
- **`backdrop-filter`（blur）は使わない。** Safari で、このシートに `backdrop-filter` を
  掛けると**シートが覆っている領域だけ**背後の画像が `src` 変更後に再描画されない
  （リストビューのサムネイルをタップするとメタデータだけ切り替わり、画像はシートと重なった
  部分だけ 1 回分古いまま残る。重なっていない部分は正しく更新される。シートを閉じると反映される。
  Chrome では再現しない）。**blur を戻す / 外すの A/B テストで原因を確定済み**（2026-07-30）。
  モックアップは blur 前提だが、**ぼかしの代わりに背景の不透明度を上げて可読性を確保する**。
  ここを blur に戻さないこと。詳細は knowledge.md
- 出現アニメーション: `translateY(100px) + opacity 0 → 0 / 1`（0.28s、下からスクロールイン）
- **表示中に前後移動したら内容も追従して更新する**

**表示要素**（上から）:

| 要素 | 内容 |
| --- | --- |
| 削除ボタン | **右上に配置**（旧実装から移動）。5.1 参照 |
| 評価 | ★×5 を**大きく表示**（30px。旧実装の「小さくて押しにくい」への対策）。タップで変更、同じ星の再タップで 0 |
| ファイル名 | bold・折り返し可 |
| メモ | `annotation`。空なら行ごと非表示。`white-space: pre-wrap` |
| フォルダ | 所属フォルダ**すべて**をバッジで表示。タップでそのフォルダへ移動（Lightbox を閉じる） |
| タグ | 付与タグ**すべて**をバッジで表示。空なら行ごと非表示。**タップでそのタグで絞り込む**（6.3） |
| サイズ | `1,234 KB` 形式 |
| 形式 | 拡張子を大文字表示 |
| 解像度 | `1234 x 1234 px` |
| 更新日時 | `yyyy/MM/dd hh:mm:ss`（`modificationTime`）。**「最終変更」の行は表示しない**（プラグイン API に `modifiedAt` しか無く同値になるため。ユーザー決定 2026-07-18。バックエンドは互換のため `lastModified` を返し続けるが表示には使わない） |

### 6.1 削除

1. 削除ボタンをタップ → `window.confirm("{ファイル名}を削除しますか？")`
2. OK → `moveToTrash([id])`。実行中はボタンを `opacity: 0.5` + 無効化
3. 成功: `items` store から除去し、**次のアイテムへ移動**（末尾だった場合は前へ。
   1 件も残らなければ Lightbox を閉じる）
4. 失敗: 何も消さずトースト表示

### 6.2 レーティング変更

- 楽観的更新: 表示を即時変更 → `updateItem({star})` → 失敗時ロールバック + トースト
- グリッドのセル表示（`items` store）にも反映される（`patchItem`）

### 6.3 タグ表示・タグでの絞り込み

移植元 Simple Eagle にはあった表示要素だが、モックアップに無かったため仕様から欠落していた
（2026-07-30 に発見。knowledge.md「仕様策定」章）。モックアップは機能の網羅性の一次情報ではない。

- バッジの見た目はフォルダバッジと揃える（`rgba(255,255,255,.14)` 地・角丸 20px・12px）
- **タップ動作**: query の `tags` を**そのタグ 1 つで置き換え**て `router.push` し、
  Lightbox を閉じる（`image` を除去）。**現在のフォルダと他のフィルタ（stars / exts /
  keyword）は維持する**
  - フォルダを跨いで探したい場合はパンくずの「すべて」から辿れるため、
    勝手に `all` へ移動はしない（フィルタ文脈を壊さない方針。grid.md 3.2 と同じ考え方）
  - 複数タグの AND 絞り込みはフィルタダイアログで行う（ここは 1 タグの導線に絞る）

## 7. エッジケース

| ケース | 挙動 |
| --- | --- |
| query の `image=` がロード済みに無い | **初回ページのロード完了を待ってから判定**し、無ければ Lightbox を開かず query を除去（base.md 12 章。単品取得 API はオープン課題） |
| 画像の読み込み失敗（`get_image` がエラー） | 代替表示（アイコン + ファイル名）。前後移動・削除は可能なまま |
| 自動リロードとの競合 | Lightbox 表示中はポーリング停止（grid.md 6.2） |
| 巨大画像 | バックエンドが `max_file_size` 超過分を JPEG 圧縮して返す（既存機能）。フロントは関知しない |
| 削除確認中の前後移動 | `confirm` はモーダルなので操作不能。問題なし |
