# グリッドビュー 仕様書

## 1. 概要

Mobile Eagle の基本画面。ヘッダー・パンくずリスト・サムネイルグリッドで構成し、
ここから他のビュー（フォルダツリー / フィルタ / 設定 / Lightbox）をモーダルで呼び出す。
**画面遷移はしない**（ルートは `/folder/:folderId` のみ。[base.md 7 章](base.md)）。

この仕様書はフィルタダイアログ・子フォルダセル・複数選択（アクションビュー）・自動リロードも含む。

## 2. 関連ドキュメント

- 共通基盤: [base.md](base.md)（テーマ・ルーティング・store・API・描画方式は全て base.md に従う）
- モックアップ: `.claude/design/Mobile Eagle.dc.html`（レイアウト・数値の一次情報）

## 3. 画面構成

上から順に、ヘッダー（sticky）→ パンくずリスト → サムネイルグリッド（内部スクロール）。
画面右下にグリッドコントローラー、複数選択中は画面下端にアクションビューを固定表示する。

### 3.1 ヘッダー

高さ 52px、`position: sticky; top: 0`、下ボーダー。**アプリ名は表示しない**。

| 位置 | ボタン | 動作 |
| --- | --- | --- |
| 左 | ハンバーガー | フォルダツリーを開く（`ui.isTreeOpen = true`） |
| 右 | フィルタ | フィルタダイアログを開く。**フィルタ適用中は背景 `--accent` + 白アイコン** |
| 右 | 複数選択 | 選択モードをトグル。**モード中は背景 `--accent` + 白アイコン** |
| 右 | 設定 | 設定ダイアログを開く（旧実装のフォルダツリー内からヘッダーへ移動） |

- ボタンは 40×40px、角丸 9px、ホバー `--hover`
- 「フィルタ適用中」は route query に stars / exts / keyword / tags のいずれかがあること

### 3.2 パンくずリスト

- `すべて > 親 > 現在地` の形式。先頭は常に「すべて」（`/folder/all`）。
  未分類フォルダ表示中は `すべて > 未分類`
- 区切りは chevron アイコン。折り返し可（`flex-wrap`）
- 現在地は `--fg` / bold、祖先は `--accent`。クリックで該当フォルダへ `router.push`
- 各項目は `max-width: 140px` で ellipsis
- **フォルダを切り替えてもフィルタ query は維持する**（`image` だけ落とす）。
  旧実装の「フィルタ文脈の喪失」（base.md 2 章）を繰り返さないため。
  遷移処理は `composables/use-folder-navigation.ts` に置き、フォルダツリーからも使う

### 3.3 サムネイルグリッド

- `display: grid; gap: 3px; padding: 3px; grid-template-columns: repeat(N, minmax(0, 1fr))`
  （N はグリッド列数。**inline style で指定**する — Tailwind の動的クラス生成は purge で
  消えるリスクがあるため使わない）
- **`1fr` ではなく `minmax(0, 1fr)` を使う**。`1fr` は `minmax(auto, 1fr)` と等価で、
  `content-visibility` セルの `contain-intrinsic-size` が min-content 幅として効き、
  列数を増やしても列が縮まず画面外へはみ出す（knowledge.md に詳細）
- グリッド最下部に 120px の余白（グリッドコントローラーがサムネイルに被らないように）
- 0 件時は「表示する画像がありません」を中央表示

**グリッドセル**（`GridCell.vue`）:

- サムネイル: アスペクト比 1:1、背景 `--thumb`、角丸 6px、`object-fit` は設定値（cover / contain）。
  `src` は `/api/eagle/get_thumbnail_image?id=`、`loading="lazy"`
- セルには `content-visibility: auto` + `contain-intrinsic-size` を指定（base.md 11 章）
- フォーマットバッジ: 左下。拡張子を大文字表示（`JPG` など）。黒半透明地に白文字 9px
- レーティング: サムネイル下に `★★★☆☆` 形式（11px 中央揃え）。点灯は `#f5b301`、
  消灯は `--fg` の opacity 0.28。**未評価（star なし）は 0 扱い**
- 選択マーカー（選択モード時のみ。5 章）: セル全面に `--accent` の半透明オーバーレイ + 枠、
  右上に青丸 + 白チェック。範囲選択の始点は白チェックの代わりに「A」

**セルのクリック**:

| 状態 | 動作 |
| --- | --- |
| 通常 | Lightbox を開く（query に `image={id}` を push） |
| 選択モード | 選択のトグル |
| 範囲選択モード | 始点/終点の指定（5.2） |

### 3.4 無限スクロール

- スクロールコンテナは `<main>`（内部スクロール。base.md 11 章）
- 一覧末尾に番兵要素を置き、`IntersectionObserver`（`rootMargin: '100px'`）で検知して
  `items.loadNextPage()` を呼ぶ
- 発火条件: `!isLoading && hasMore && !isReloading`（自動リロード中の誤発火を抑止）
- 1 ページ = `ITEM_GET_COUNT`（600 件）。`offset` はページ番号（base.md 9 章）
- **フォルダ・フィルタが変わったら**（route watch）: `loadFirstPage()` でリセットし、
  スクロール位置を先頭へ戻す。**query の `image`（Lightbox）の変化はリセットの対象にしない**
  （base.md 7 章）

### 3.5 グリッドコントローラー

画面右下に固定表示（`position: fixed; right: 14px; bottom: 18px`。
**選択モード中は `bottom: 86px`**（アクションビューの上に退避）。Lightbox 表示中は非表示）。

**表示切り替えボタン**（38×38px）:

- `object-fit: cover ⇔ contain` をトグルする。設定として永続化（settings.md）
- アイコンは `--fg` ベース（ダークモードで見えなくなる旧問題への対策）:
  - cover 時: `--fg` の正方形
  - contain 時: `--fg` opacity 0.5 の正方形の中央に `--fg` の縦長長方形

**サイズ変更ボタン**（`[− | ＋]` のボタングループ）:

- **`＋` = セル拡大 = 列数を減らす**（最小 1 列）
- **`−` = セル縮小 = 列数を増やす**（最大列数 = `floor(コンテナ幅 / 60px)`。
  デザイン指示書には `100% / 64` の記述もあるが、INSTRUCTION.md の 60px を採用する）
- 旧実装と +/− の意味が逆になっている点に注意（INSTRUCTION.md の要件。「+ でグリッド数が
  増える」旧仕様は直感的でなかった）
- 列数はブレークポイント別ではなく**単一の数値**として保持・永続化する（settings.md）。
  画面回転・リサイズ時は最大列数で clamp する
- ボタンに `touch-action: manipulation`（連打でブラウザズームが働く既知問題への対策）

### 3.6 子フォルダセル

実フォルダ表示中、グリッドの先頭に**現在フォルダ直下の子フォルダ**をセルとして並べる。
パンくずは「戻る」導線・フォルダツリーは操作コストが高いため、グリッドから直接「潜る」
導線を確保する（INSTRUCTION.md。移植元 Simple Eagle の `ImageListFolder.vue` に相当）。

**表示条件**:

- 現在フォルダが**実フォルダ**のときのみ。**`all`・`uncategorized` では表示しない**
- **フィルタ適用中も常に表示する**（フィルタが絞るのは画像のみ。潜る導線は常に残す）
- データ源は `folders` store（`findPath(folderId)` の末尾要素の `children`）。
  並び順は API が返す順（= フォルダツリーと同じ）。バックエンドの変更は不要

**セルの見た目**（`FolderCell.vue`。`components/grid/`）:

- 画像セルと同じグリッドに置き、**画像より前**に配置する
- サイズは画像セルと同じ（1:1 + 星行ぶんの高さ = `cellHeight`。行の高さを画像セルと揃える）
- 背景 `--thumb`、角丸 6px。中央にフォルダアイコン（SVG、`--accent`）、
  その下にフォルダ名（`--fg`、ellipsis）と件数（`--muted`）
- 件数はフォルダツリーと同じ**合算件数**（`folders.totalImageCount()` を流用。
  二重計上の既知課題も folder-tree.md と共通）
- `content-visibility` は指定しない（先頭に少数並ぶだけで仮想化の対象にする意味がない）

**挙動**:

- タップで該当フォルダへ移動（`use-folder-navigation.ts`。フィルタ query は維持、`image` は落とす）
- **選択モード中は表示したまま選択不可**: タップしても選択されず、フォルダ移動もしない
  （一括操作中の誤遷移防止）。A→B 範囲選択（5.2）の「一覧の表示順」からも除外する
  （範囲の対象は画像のみ）
- 無限スクロールのページングとは無関係（1 ページ目の前に常に全件表示する。
  `items` store には入れない）
- 自動リロード（6 章）でリロードが実行されたときは `folders.load()` も併せて実行し、
  子フォルダと件数を追随させる

## 4. フィルタダイアログ

ヘッダーのフィルタボタンから開くモーダル（上寄せ・max-width 480px・max-height 88vh）。

| 項目 | UI |
| --- | --- |
| 評価 | `☆☆☆☆☆`（0）〜`★★★★★`（5）の 6 段階**チップ（複数選択可）** |
| 拡張子 | `folders` store の `extList`（バックエンド拡張。base.md 10 章）から生成したチップ（複数選択可）。大文字表示 |
| キーワード | テキスト入力。プレースホルダー「検索キーワードを入力」。**対象はファイル名 + メモ、空白区切りは AND**（Eagle 本体の検索窓と同じ挙動。backend/base.md 6.1.1） |
| タグ | テキスト入力。プレースホルダー「タグを「,」区切りで入力」+ 説明文「複数のタグを「,」区切りで入力してください」 |

ボタン（右寄せ）: **キャンセル / フィルタ解除 / 決定**（「解除」ではなく「フィルタ解除」。INSTRUCTION.md）

- 開いたとき、現在の route query から**ドラフト状態**へコピーする（編集中は適用されない）
- **決定**: ドラフトを query に反映して `router.push` → ダイアログを閉じる。一覧は route watch で
  1 ページ目から再取得される
- **フィルタ解除**: query からフィルタを全て除去して閉じる
- **キャンセル / 背景クリック / ×**: ドラフトを破棄して閉じる
- フィルタは**サーバー側で適用**される（base.md 9 章。stars はバックエンド拡張）

## 5. 複数選択・アクションビュー

### 5.1 アクションビュー（基本）

選択モード中、画面下端に固定表示（`position: fixed; left: 0; bottom: 0; width: 100vw; height: 72px`）。
モードによって内容が変わる（`selection.actionMode`）:

| actionMode | 左 | 右 |
| --- | --- | --- |
| `default` | 「{n} 件選択中」 | 「A→B」ボタン / ★ボタン / **フォルダ移動ボタン** / 削除ボタン |
| `range` | 「始点と終点を選んでください」 | キャンセル |
| `rating` | ★×5（26px。タップで値を選択、同じ星の再タップで 0） | 実行 / キャンセル |
| `move` | 「{n} 件を「{移動先フォルダ名}」に移動しますか？」（ellipsis 可） | 実行 / キャンセル |
| `delete` | 「{n} 件を削除しますか？」 | 実行 / キャンセル |

- フォルダ移動ボタンは★と削除の間。アイコンは「フォルダ + 矢印」（drive_file_move 相当の SVG）

- 選択モードを抜ける（ヘッダーの複数選択ボタン再タップ）と選択・actionMode を全てクリア
- 実行中はボタンを `opacity: 0.5` + クリック不可にする（二重実行防止）

### 5.2 範囲選択（A→B）

1. 「A→B」タップで `range` モードへ
2. サムネイルをタップすると「A」マーカーが付く（再タップで解除）
3. 「A」が付いた状態で**別の**サムネイルをタップすると、一覧の表示順で A からタップ位置までを
   すべて選択状態にする（既存の選択は維持・追加）
4. 「A」マーカーは通常のチェックに変わり、`default` モードへ戻る
5. キャンセルでいつでも `default` へ（「A」も解除）

INSTRUCTION.md の初期案（A→B ボタン自体をトグルにする）から、モックアップの
「range モード中はアクションビューの内容が切り替わり、キャンセルで戻る」方式へ意図的に変更している。

### 5.3 一括レーティング

- `rating` モードで値を選び「実行」→ 選択中の全アイテムに `updateItem({star})` を並列実行
- 楽観的更新: 先に画面へ反映し、失敗したアイテムのみ元の値へロールバック + トースト
- 完了後は `default` モードへ（選択は維持する）

### 5.4 一括削除

- `delete` モードで「実行」→ `moveToTrash({itemIds})`
- 成功: 対象を `items` store から除去し、選択をクリアして `default` モードへ。
  **`folders.load()` を再実行**してツリーと子フォルダセル（3.6）の件数を更新する
- 失敗: 何も消さずトースト表示

### 5.5 フォルダ移動

1. フォルダ移動ボタンをタップ → **移動先選択ダイアログ**を開く（`ui.isMoveOpen`）
   - フィルタ・設定と同じモーダル枠（上寄せ・max-width 480px・max-height 88vh・z-index 70）
   - タイトル「移動先フォルダを選択」+ ×ボタン
   - 本文はフォルダツリー（folder-tree.md の行コンポーネントを流用。件数表示・展開/折りたたみ可。
     **展開状態は本体のフォルダツリーとは独立**）
   - 表示するのは**実フォルダ + 「未分類」**（「すべて」は移動先にならないため出さない。
     モックアップには「すべて」行があるが意図的に省く）。
     **「未分類」を選ぶと、アイテムに登録されている全フォルダ ID を削除する**
     （= `folders` を空にする。base.md 10 章）
   - フッターに「キャンセル」ボタン。キャンセル / × / 背景クリックで閉じるだけ（状態は変わらない）
2. ツリーのフォルダをタップ → ダイアログを閉じ、`selection.moveTargetId` にセットして
   `move` モードへ（アクションビューに確認文言が出る）
3. 「実行」→ `moveToFolder({itemIds, folderId})`（base.md 10 章の拡張 API）。
   実行中はボタン無効化
   - 成功: 選択と `moveTargetId` をクリアして `default` モードへ。**現在ビューが移動先と
     異なる実フォルダ・未分類の場合は対象を一覧から除去**する。`all` 表示中と
     「現在ビュー = 移動先」の場合は残すが、**`patchItem()` で各アイテムの `folders` を
     更新**する（実フォルダなら `[移動先]`、未分類なら `[]`。Lightbox のフォルダ表示との
     不整合を防ぐ）。`folders.load()` を再実行してツリーの件数を更新する
   - 失敗: トースト表示 + **`loadFirstPage()` で一覧を再取得**する（サーバー側で一部だけ
     移動済みになり得るため、表示を実態に合わせる。base.md 10 章）
4. 「キャンセル」→ `moveTargetId` を破棄して `default` へ
- **移動は「置換」**: 複数フォルダに属するアイテムも、移動後は移動先 1 フォルダだけに属する
  （base.md 10 章）

## 6. 自動リロード

Eagle 側での変更を検知して一覧を自動更新する（改造版 kairin の最終方式を踏襲）。
検知できるのは**アイテムの追加・削除と、先頭アイテムの変更のみ**
（先頭以外のアイテムの star 変更などは検知できない割り切り）。

### 6.1 変更検知（シグネチャ比較方式）

- **現在の表示コンテキストと同じ query**（フォルダ + フィルタ）で `GET /list?limit=1&offset=0` を
  ポーリングし、`"${先頭のid}:${先頭のmodificationTime}:${該当総数}"` をシグネチャとして
  前回値と比較する（0 件なら `"empty:0"`）
- **総数（`totalCount`）を含めるのは削除を検知するため。** 先頭 1 件だけをシグネチャに
  していた当初の方式では、**先頭以外のアイテムを削除しても値が変わらず一覧が更新されなかった**
  （2026-07-30 に実機で判明）。並び順が `importedAt` 降順なので追加は必ず先頭に現れて検知できるが、
  削除は先頭以外で起こり得る
- `totalCount` は `/list` のレスポンスに含める（backend/base.md 8.1）。バックエンドは
  どうせ全件フィルタしてから slice しているので**追加コストは無い**。
  専用エンドポイントを作るとフィルタ条件の組み立てが二重管理になるため作らない
- 変わっていたらリロードを実行する
- Eagle の library-info（`modificationTime`）は**画像追加で更新されないため使わない**
  （改造版で実証済みの罠）

### 6.2 ポーリング制御

- 間隔は設定値（既定 10 秒、2〜120 秒。settings.md）。設定変更時はタイマーを再起動
- **停止する条件**: 設定 OFF / タブ非表示（`document.hidden`）/ Lightbox 表示中 /
  **選択モード中**（リロードで選択が壊れるため）/ 一覧ロード中 / 認証ダイアログ表示中（auth.md）/
  **ライブラリ再読み込み中**（古いデータが返るため。[library-reload.md](library-reload.md)）
- タブ復帰時（`visibilitychange` → visible）: 300ms デバウンス後に**即座に 1 回チェック**し、
  変更があればリロード、その後ポーリング再開（モバイルブラウザの連続発火対策）
- 初回チェックは基準シグネチャの記録のみ（リロードしない）。取得失敗時は判定せず次回へ。
  **再ログイン後の再初期化時（auth.md 5 章）も基準シグネチャをリセットして初回扱い**にする
- **表示コンテキスト（フォルダ・フィルタ）が変わったときも基準シグネチャをリセットする**。
  シグネチャは query 単位の値なので、リセットしないと切替直後に必ず「変化あり」と誤判定する

### 6.3 リロード動作

- `items.reloadAll()`: 現在表示中の範囲（`pageCount × 600` 件）を
  **`limit = pageCount × 600, offset = 0` の 1 リクエスト**で再取得してまるごと差し替える
  （ページ順次取得だと、取得中のアイテム増減で重複・欠落が起きるため。バックエンドの
  `limit` は JS 側 slice なので上限なし）。完了後 `pageCount` を再設定する
- スクロール位置を保持する（差し替え前に記録し、`nextTick` 後に復元）
- リロード中は `isReloading` を立て、IntersectionObserver の発火を抑止する。
  解除は完了の 200ms 後（オブザーバー誤発火の余韻対策）
- リロード実行時は `folders.load()` も併せて実行する（子フォルダセル・ツリーの件数を
  追随させる。3.6）。ポーリングの空振り時（シグネチャ不変）には実行しない
- **ライブラリ再読み込みの完了時は、シグネチャを比較せずに 1 回読み直す**（自動更新 OFF でも行う）。
  基準シグネチャは捨てる（残すと直後に 2 回目の読み直しが走る）。選択モード中・Lightbox 表示中・ロード中は
  保留し、条件が外れたら実行する（[library-reload.md](library-reload.md) 4.5）
- ON/OFF ボタンは**グリッドビューには置かない**（設定ダイアログのみ。INSTRUCTION.md）

## 7. エッジケース

| ケース | 挙動 |
| --- | --- |
| フィルタ結果 0 件 | 「表示する画像がありません」。フィルタボタンは適用中表示のまま |
| 子フォルダはあるが画像 0 件 | 子フォルダセルは表示し、その下に「表示する画像がありません」を表示する |
| 選択モード中のフォルダセルのタップ | 何もしない（選択も遷移もしない。3.6） |
| 選択モード中にフィルタ / フォルダ変更 | 選択モードを解除する（選択対象が画面から消えるため） |
| 範囲選択の A と終点が同一 | 「A」の解除として扱う（範囲選択しない） |
| 移動先 = 現在表示中のフォルダ | 成功扱い（一覧から除去しない。実質所属の整理になる） |
| 0 件選択で移動・レーティング・削除 | ボタンは押せるが実行ボタンを無効化（または「0 件」表示のまま実行を no-op に） |
| 一括操作中の画面遷移 | 実行中はアクションビューのボタンを無効化。遷移自体は妨げない（結果はトーストで通知） |
| 自動リロードとユーザー操作の競合 | 選択モード・Lightbox・ロード中はポーリング自体を止める（6.2） |
| 回転・リサイズで列数が最大を超過 | 最大列数へ clamp（設定値も更新） |
