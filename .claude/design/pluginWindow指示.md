# スマホ用画像閲覧ソフト Mobile Eagle プラグインウィンドウ画面構成仕様

## 概要

画像管理アプリ Eagle のスマートフォン用簡易UI「Mobile Eagle」のバックエンド側ウィンドウの画面構成についての仕様書です。

Eagle のプラグインメニューから起動するとウィンドウがポップアップし、接続するための情報や動作状況ログを表示します。

## 全体仕様

- 初期ウィンドウサイズ：520 x 660px（ユーザーによりリサイズ可能）
- ウィンドウ外観：タイトルや最大化ボタン、閉じるボタンなどが付いた標準的なウィンドウタイトルバー
- デザイン：すでに存在するフロントエンドとデザインを合わせる。

## 構成要素

### 配置順
- ユーザーの必要度が高いものから順番に上から配置
  - サーバーON/OFFトグルスイッチ
    - 現在の状態表示
  - アクセス情報
    - QRコード
    - アクセス用URL
  - 設定
    - IPアドレス選択 / ポート番号入力
    - ログインパスワード
    - 適用ボタン
  - ログ

### サーバーON/OFF
- ON/OFF状態が明確にわかるトグルスイッチ。
- スイッチの下に現在の情報を表示する
  - 「サーバー起動中」、「サーバー停止中」、「サーバーの起動に失敗。詳細はログをご覧ください。」
  - それぞれの状態がわかるように色を変更する

### アクセス情報
- スマートフォンからアクセスするためのQRコード
- アクセス用 URL はテキスト入力ボックス
  - ユーザーの編集は不可。
  - クリックするとクリップボードにコピーされる。
  - 小さな文字で「クリックするとクリップボードにコピーされます」と表記

### 設定
- IPアドレス選択
  - 使用可能な IP アドレスをドロップダウンで選択する。
- ポート番号入力
  - 5桁までの数値入力
  - IPアドレス選択の隣に並べる。
- ログインパスワード
  - ウィンドウ横幅いっぱいのテキスト入力ボックス
  - 目玉ボタンを配置し、可視・不可視（***）状態を切り替える
  - 下に小さな文字で「空欄はパスワード認証をしません。英数記号のみ最大128文字。」と表記
- 保存ボタン

### ログ
- `<pre>` でログを表示する。
- 最大200件表示。スクロール可能。
- ウィンドウサイズを広げると、合わせてログエリアも広がる。

ログサンプル：
```
[13:15:01.671] サーバーを起動しました 0.0.0.0:8000
[13:15:01.667] /api/eagle のエンドポイントを登録しました
[13:15:01.658] プラグインを開始しました
```
