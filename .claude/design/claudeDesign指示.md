# スマホ用画像閲覧ソフト Mobile Eagle 画面構成仕様

## 概要

- 画像管理アプリ Eagle をスマホ用に簡易表示するアプリ
- ブラウザアプリなのでPCも使えるが、メインターゲットはスマホ
- サムネイルグリッドビューを基本とし、フォルダ切り替え、Lightbox表示、評価などの機能を備える
- テーマ切り替え対応（ダーク / ライト / 自動）

## デザインについて

- Eagleのようなシンプルなデザイン。ベース色はライトでは白、ダークでは #232729 
  - ダークモードでは文字色が白 #fff になる
- ボタン：角丸
- チェックボックス：標準のチェックアイコンは表示しない。選択中は背景色が変わる＋チェックアイコンを表示
- ラジオボタン：標準のラジオアイコンは表示しない。ボタングループ。選択中は背景色が変わる＋チェックアイコンを表示
- テキスト入力：font-size:16px 以上とする。iPhoneはフォントサイズの小さい入力ボックスがズームされてしまうため
- 設定画面やフィルタ画面は「見出し/内容」を縦並びにする。横並びにしない

## 画面構成

- 画面上からヘッダー、パンくず、サムネイルグリッドを配置

## ヘッダ

- 構成
  - 左寄せ：ハンバーガーボタン
  - 右寄せ：フィルタボタン、複数選択ボタン、設定ボタン
- ハンバーガーボタン
  - 後述する「フォルダツリーダイアログ」を表示
- フィルタボタン
  - 漏斗のようなアイコン
  - クリックすると後述する「フィルタダイアログ」を表示
  - フィルタ適用中はボタン背景が青くなる
- 複数選択ボタン
  - チェックボックスアイコン
  - クリックするとサムネイル複数選択モードになり、後述する「アクションビュー」を表示
  - モード適用中はボタン背景が青くなる
- 設定ボタン
  - クリックすると後述する「設定ダイアログ」を表示

## パンくずリスト

- `祖先 > 親 > 現在地` のような表示
- 親、祖先クリックでフォルダ移動

## サムネイルグリッド

- 画像をグリッド表示 display:grid
- ページャーは無く、無限スクロール
- グリッドサイズは可変。最小1、最大 100%/64
- グリッドセルをクリックすると後述するLightboxを表示
- グリッドセル表示要素
  - 画像サムネイル：1x1で object-fit:contain / cover が選択できる
  - 画像フォーマット：サムネイルの左下にバッジ表示
  - 5段階★レート：`★★★☆☆` のような表示。`☆`は★を opacity:0.3 で表示。`★`は黄色で目立たせる。サムネイルの下
  - チェックマーク：複数選択モードの時にクリックすると表示される。背景青にチェックマーク
- 画面右下にグリッドコントローラーを position:fixed で表示
- グリッドコントローラーの下のサムネイルが見えないので、グリッドの一番下はグリッドコントローラー分の余白が必要
  
### グリッドコントローラー
- 「サムネイル表示切り替えボタン」、「サムネイルサイズ変更ボタン」を表示
- サムネイル表示切り替えボタン
  - サムネイル表示方法を object-fit: contain / cover の切り替えする
  - アイコンデザイン
    - cover: 黒い正方形
    - contain: グレーの正方形の中央に縦長の黒い長方形を置く
- サムネイルサイズ変更ボタン
  - `+` と `-` のボタングループ
  - `+`: グリッドの分割数が**減る**
  - `-`: グリッドの分割数が**増える**


## フィルタダイアログ

- 「フィルタ」ボタンから呼び出されるモーダルダイアログ
- 設定項目
  - 評価：`☆☆☆☆☆` 〜 `★★★★★` までの６段階チェックボックス
  - 拡張子：WEBP / JPG / PNG など拡張子のチェックボックス
  - キーワード：テキスト入力。プレースホルダー「検索キーワードを入力」
  - タグ：テキスト入力。プレースホルダー「タグを「,」区切りで入力」。説明テキスト「複数のタグを「,」区切りで入力してください」
- ボタン：右寄せ。キャンセル / フィルタ解除 / 決定

## アクションビュー

- 複数選択ボタンから呼び出される
- モードによって表示するボタンが変わる。現在は複数選択モードのみ
- 表示位置　position:fixed / width:100vw / height:72px / left:0 / bottom:0
- 表示要素：
  - 左寄せ：選択個数表示
  - 右寄せ：範囲選択ボタン、レーティングボタン、削除ボタン
- 範囲選択ボタン
  - ボタン表記は「A→B」
  - クリックするとアクションビューの内容が変わる
    - 左寄せ：「始点と終点を選んでください」
    - 右寄せ：キャンセル
  - この状態でサムネイルをクリックするとサムネイルに付くのは「チェックマーク」ではなく「Aマーク」になる
    - チェックマーク同様、もう一度クリックで解除
  - 「A」がついた状態で別のサムネイルをクリックすると「A」からクリック地点まで連続で選択状態になる
    - 「A」マークは普通のチェックマークに変化する
  - その後アクションビューは初期状態に戻る
- レーティングボタン
  - クリックするとアクションビューの内容が変わる
    - 左寄せ：グレーの「★★★★★」
      - クリックすると左からクリック位置までの★を黄色にする（レートが変わる）
      - 他の★をクリックするとレートが変わる
      - 現在のレートをクリックすると全てグレーになる（レート0）
    - 右寄せ：実行 / キャンセル
- 削除ボタン
  - クリックするとアクションビューの内容が変わる
    - 左寄せ：「削除しますか？」
    - 右寄せ：実行 / キャンセル


## フォルダツリーダイアログ

- ハンバーガーボタンから呼び出すモーダル。画面左端に幅320px 高さ100vhで表示
- モーダルの外側をクリックすると閉じる
- またはフォルダアイテムをクリックしてフォルダ移動すると閉じる
- Windowsのエクスプローラーのような折りたたみリスト
- `▶ {フォルダ名}（{アイテム個数}）` を表示。
  - 子フォルダが無ければ `▶` は表示しない
- クリックでフォルダに移動。クリック領域はテキスト部分だけではなく、横幅いっぱい
- `▶`クリックで子フォルダ展開。`▽`に変わる
  - 子フォルダはインデントする

## 設定ダイアログ

- 設定ボタンから呼び出す
- 設定項目：
  - テーマ選択：チェックボックス
    - ライト / ダーク / 自動
  - 自動更新：チェックボックス
    - 有効 / 無効
  - 自動更新間隔（秒）：入力ボックス
    - 2〜120秒。規定10秒
  - ファイルサイズ上限（KB）：入力ボックス
    - 規定は空欄
    - 説明：ファイルサイズがこの数値より大きい画像は圧縮して表示する。0 = 圧縮しない / 空欄 = 768
  - JPEG圧縮率：入力ボックス
    - 規定は85
    - 説明：空欄 = 85

## LightBoxビュー

全画面のモーダル
サムネイルをクリックすると呼び出される

- 表示要素
  - 背景：#232729 / opacity:1
  - 画像：
    - 画面全体で object-fit:contain / object-position: center
    - 画像をクリックすると後述するメタデータビューを表示。再度クリックすると閉じる
  - 閉じるボタン
    - 画面右上に position:fixed
  - 前後アイテム移動ボタン
    - 透明なボタン。クリックすると押下中に薄く表示
    - 画面全体の両端に width:min(200px, 20vw) / height:100vh で表示
    - メタデータビュー表示中でも移動する

### メタデータビュー

- Lightboxの中にオーバーレイで表示する
- position:fixed; width:100vh; max-height:55vh; left:0; bottom:0; overflow:auto; background:rgba(0,0,0,0.5);
- 画面の下からスクロールインする。translateY:100px; opacity:0; から フェードイン
- メタデータビュー表示中に他の画像に切り替わったらメタデータビューの内容も更新する
- 表示要素：
  - ゴミ箱ボタン：右上に position:absolute; で表示
    - クリックするとブラウザ標準の alert で削除確認
    - 「{ファイル名}を削除しますか？」
  - 評価：`★★★★★` を大きく表示。それぞれクリックで評価を変更
  - ファイル名
  - メモ：アイテムに付与されているメモテキスト
  - フォルダ：登録フォルダをバッジ形式で表示。クリックでフォルダに移動
  - サイズ：画像サイズ
  - 形式：JPGなど拡張子
  - 解像度：1234 x 1234px
  - 更新日時： yyyy/MM/dd hh:mm:ss
  - 最終変更： yyyy/MM/dd hh:mm:ss

## 初回デザインへの変更指示

**メタデータビューを変更：**

- ゴミ箱ボタン
  - クリックするとブラウザ標準の alert で削除確認
  - 「{ファイル名}を削除しますか？」
- メモ
  - アイテムに付与されているメモテキスト
  - ファイル名の下に追加

**グリッドコントローラーを変更：**

- ダークモード時、サムネイル表示切り替えボタンのアイコンカラーが黒いので見にくい
- 色を `var(--fg)` にする
- contain 時は下記のようにする
```
<button>
  <span style="background:var(--fg); opacity:0.5;"> // 正方形
  <span style="background:var(--fg);">  // 縦長
</button>
```

**Lightboxビューを変更：**

- 前後アイテム移動ボタン
  - 画面全体の両端に width:min(200px, 20vw) / height:100vh で表示
  - クリックした時にボタン範囲が見えるようにする
    - `&:active` に `background: #ffffff42` を指定

**フィルタダイアログ、設定ダイアログを変更：**

- 現在は align-itemns:flex-end になっているが、 flex-start にする


Lightbox：前後アイテム移動ボタンのアクティブ時背景色が反映されていません。
`.scp1:active` に設定されていますが、`background:transparent`が直書きされているので詳細度が低いです。

**フォルダ移動ボタンを追加：**

- 選択モードで表示されるアクションビューにフォルダ移動ボタンを追加
- レーティングボタンとゴミ箱ボタンの間に追加する
- アイコンはフォルダにファイルを入れるような感じ。またはフォルダに矢印が入るような感じ
- クリックするとフィルターや設定のようなモーダルダイアログが出現する
- ダイアログの中身は、フォルダツリービューと キャンセルボタンがある。
- キャンセルをクリックするとダイアログが閉じるだけで、クリック前と変わらない
- フォルダツリーからフォルダをクリックすると、ダイアログが閉じてアクションビューの内容が変わる
  - 左寄せ：「{選択件数}件を"{選択したフォルダ}"に移動しますか？」
  - 右寄せ：実行 / キャンセル

**認証ダイアログを追加：**

- 起動すると、最初に認証ダイアログが表示される
- デザインはフィルターや設定と同じモーダル
- 表示項目
  - パスワード入力（*で不可視）
  - エラー時のメッセージ表示
  - OKボタン
- 認証を成功したらダイアログを閉じる
- 認証に失敗したら、「パスワードが間違っています」というエラーメッセージを表示する。

**Lightboxにサムネイルを表示するリストビューを追加：**

- 前後の画像サムネイルを横に並べて表示するリストビューを追加。iOSの「写真アプリ」のような感じ。
- 現在選択している画像が中央になる。
- リストはドラッグでスクロール可能。ドラッグ距離4px以上ならドラッグと判断。それ以外はクリック
- 前後の画像は opacity:0.6 にする。
- サムネイルは正方形にトリミングする。object-fit:cover
- サムネイルサイズは 64 × 64px。
- サムネイルをクリックすると、Lightboxをその画像で更新
- 詳細画像の下に配置するので、詳細画像のエリアはリストビューの高さ分小さくなる

**メタデータビューの表示座標を変更：**

- 上記のリストビューが追加されるので、メタデータビューの表示座標もその高さ分移動する。

**メタデータビューから最終更新を削除：**

- メタデータビューから「最終更新」を削除して「更新日時」だけにする
- APIでデータを取得できないので同じ値になってしまうため
